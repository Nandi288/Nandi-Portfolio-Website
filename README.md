# Developer Portfolio | Nandi-Gabriella Shandu

Personal portfolio website showcasing my software development projects and technical skills as a final-year Application Development student.

## Projects

* **Eco Rewards System:** A full-stack web application for logging recyclable waste, viewing metrics via Chart.js, and exporting PDF/Excel reports
* **HerCycle Marketplace Platform:** A KZN Imbokodo Hackathon project focused on the seller side to help female entrepreneurs advertise period and menstrual health products
* **Security Management System (Pirana Guarding):** A web app for a security enterprise to manage guard rosters and check-ins
* **Student Management System:** A collaborative cloud project built with .NET and Azure

## Tech Stack
