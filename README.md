# 👩‍💻 Developer Portfolio | Nandi-Gabriella Shandu

A clean, responsive personal portfolio website showcasing my software development projects, technical skills, and academic journey as a final-year Application Development student.

Designed with a modern, dark-mode sidebar aesthetic and built with pure **HTML5**, **CSS3**, and **Bootstrap 5** for maximum performance and scannability.

---

## 🌟 Featured Projects

### 1. ♻️ Eco Rewards System (Smart Recycling App)
* **Stack:** C#, ASP.NET MVC, SQL Server, Chart.js, iTextSharp, EPPlus, Bootstrap 5
* **Description:** A full-stack web application designed to encourage sustainable habits by allowing users to log recyclable waste, track their environmental impact through interactive data visualisations, and earn redeemable rewards points.
* **Key Features:**
  * **Data Visualization:** Interactive waste metrics and user recycling analytics rendered using **Chart.js**.
  * **Document Generation:** Automated PDF transaction receipts and vouchers generated server-side using **iTextSharp**.
  * **Reporting:** Full Excel data exports for recycling reports built with **EPPlus**.
  * **Database Architecture:** Relational schema design and transactional management in **SQL Server**.

    
### 2. 🛡️ Security Management System (Pirana Guarding)
* **Stack:** C#, ASP.NET MVC, SQL Server, Azure App Services, HTML/CSS, Bootstrap
* **Description:** A full-stack web application built for a real-world security enterprise to manage guard rosters, client sites, and incident reporting.
* **Key Features:** Role-Based Access Control (RBAC), database persistence, live cloud deployment on Azure.

### 3. 🎓 Student Management System
* **Stack:** ASP.NET Core MVC (.NET 8), Azure Cosmos DB, Azure Blob Storage, OAuth 2.0
* **Description:** A collaborative group project delivering a student record portal with enterprise-level security and cloud integrations.
* **Key Features:** GitHub/Google OAuth login, SAS-token secured image uploads to Azure Blob Storage, Azure Cosmos DB persistence.
